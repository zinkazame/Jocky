# Future Scope

Future work may include a typed AST, policy-aware validation, reviewed adapter plugins, durable evidence storage, authenticated controller sessions, a read-only evidence dashboard, reproducible builds, and formal schema/version management. Any remote capability should be developed only with explicit authorization, audit logging, least privilege, and an isolated test plan.

Potential research outcomes should be measured rather than assumed: parser quality, workflow reproducibility, evidence verification rate, resource use, failure recovery, and investigator usability.
